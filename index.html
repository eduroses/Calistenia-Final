100% gratis

Llevála al bolsillo

Los datos de entrenamiento se guardan en el dispositivo. No necesitás una cuenta ni pagar una app.

1
Publicá esta carpeta gratis
Para que el botón de instalación PWA funcione, necesitás abrirla desde HTTPS. GitHub Pages es una opción gratuita.
2
Desde el celular abrí la web
Android/Chrome: menú ⋮ → “Instalar app” o “Agregar a pantalla principal”. iPhone/Safari: Compartir → “Agregar a pantalla de inicio”.
3
Una vez instalada, funciona offline
La app incluye manifest y service worker para conservar la interfaz disponible sin conexión después de la primera carga.
